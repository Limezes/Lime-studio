LIMEZES BROWSER — ДОКУМЕНТАЦИЯ

О ПРОЕКТЕ

Limezes — браузер на базе Electron с фокусом на приватность, безопасность и свободу. Разработан Lime Studio. Версия: 0.3.9 «Функциональная»

УСТАНОВКА
🍎 macOS

Скачайте DMG под ваш процессор:

  • Apple Silicon: Limezes-0.3.9-arm64.dmg
  • Intel: Limezes-0.3.9.dmg

Откройте образ и перетащите Limezes в Applications. Приложение не подписано — на macOS 15+ откройте через ПКМ → Открыть или подтвердите в System Settings → Privacy & Security.

🪟 Windows

Скачайте Limezes-Setup-0.3.9.exe и запустите. Можно изменить путь установки. Ярлык появится на рабочем столе и в меню «Пуск».

🐧 Linux

Скачайте Limezes-0.3.9.AppImage, сделайте исполняемым (chmod +x) и запустите.

ВОЗМОЖНОСТИ
Безопасность и приватность
  • Встроенный Tor — запускается в фоне при старте. При включении VPN трафик мгновенно идёт через SOCKS5-прокси Tor.
  • VPN — по умолчанию выключен. Включение/выключение мгновенное.
  • Приватные вкладки — изолированная сессия, история не сохраняется, куки и кэш изолированы. Горячая клавиша Ctrl+Shift+N.
  • Блокировщик рекламы — на базе Ghostery. Счётчик заблокированных элементов.
  • Do Not Track — включён по умолчанию.
Навигация и вкладки
  • Вкладки сохраняются при закрытии и восстанавливаются при следующем запуске.
  • Адресная строка с поиском: Google, Bing, DuckDuckGo, Brave, Яндекс.
  • Индикатор безопасного соединения.
Веб-приложения (PWA)
  • Кнопка ⎆ появляется на HTTPS-сайтах — установка сайта как отдельного окна (мин. 480×360).
  • Повторный клик фокусирует уже открытое окно.
  • Автоматическое определение PWA-манифеста. Управление в настройках.
Переводчик
  • Встроенный перевод через Google Translate API — не требует ключа.
  • Кнопка «Показать оригинал». При блокировке API — fallback GT открывает страницу в Google Translate.
Менеджер загрузок
  • Автоматическое отслеживание. Файлы сохраняются в ~/Downloads.
  • Попап: активные (прогресс, отмена) и завершённые (открыть, показать в папке, очистить).
  • История последних 50 записей.

FAQ
Почему приложение не подписано?

Подпись требует Apple Developer Program ($99/год). Планируется в будущем.

Не работает переводчик?

Google Translate API может временно заблокировать IP. Используйте кнопку GT — она откроет страницу в переводчике напрямую.

Tor долго запускается?

Tor стартует сразу в фоне, прокси устанавливается мгновенно. Bootstrap до 100% занимает 20–60 сек и не блокирует работу.

Сохраняются ли данные?

Да: вкладки, история поиска, загрузки, настройки. Приватные вкладки историю не сохраняют.

LIME CLIPBOARD — ДОКУМЕНТАЦИЯ

О ПРОЕКТЕ

Lime Clipboard — кроссплатформенный менеджер истории буфера обмена от Lime Studio. Автоматически сохраняет всё, что вы копируете, и даёт мгновенный доступ к истории: поиск, закрепление, удаление. Работает на macOS, Windows и Linux.

УСТАНОВКА
🍎 macOS
  • Скачайте LimeClipboard-macOS.zip
  • Распакуйте — появится Lime Clipboard.app
  • Переместите в /Applications
  • Запустите. При запросе системы: System Settings → Privacy & Security → Open Anyway
🪟 Windows
  • Скачайте LimeClipboard-Windows.exe
  • Запустите двойным кликом
  • Требуется Windows 10 или 11, WebView2 Runtime (обычно уже установлен)
ВОЗМОЖНОСТИ
  • Автосохранение — всё скопированное автоматически попадает в историю
  • Поиск — быстрый поиск по содержимому всех записей в реальном времени
  • Закрепление (Pin) — важные записи не удаляются при очистке и всегда сверху
  • Копирование по клику — клик по любой записи кладёт её обратно в буфер
  • Типы контента — текст, ссылки, код — автоматическое определение и отображение
  • Тёмная тема — минималистичный тёмный интерфейс с зелёным акцентом
  • Нативное окно — стандартный titlebar macOS: перетаскивание, светофоры, сворачивание
ИСПОЛЬЗОВАНИЕ

При копировании любого текста запись автоматически добавляется в историю.

  • Клик по записи — копирует обратно в буфер обмена
  • Поиск — начните вводить текст, история отфильтруется
  • Закрепление — наведите и нажмите 📌
  • Удаление — наведите и нажмите ✕
  • Clear — удаляет все незакреплённые записи
